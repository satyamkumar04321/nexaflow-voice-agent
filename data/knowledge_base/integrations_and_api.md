# Integrations, Telephony & API

## Native CRM & Helpdesk Integrations
- Bi-directional sync with Salesforce, HubSpot, Zoho CRM, Pipedrive, and Freshdesk using OAuth 2.0.
- Automatic field mapping for leads, deal stages, call notes, and follow-up tasks within 2 seconds of call completion.
- Outbound webhooks and REST/GraphQL APIs with 1,000 requests/minute rate limits on Growth and 10,000 requests/minute on Enterprise.

## Telephony & Calendar Automation
- Supports SIP trunking, Twilio, Exotel, and WebRTC browser voice channels.
- Native Google Calendar and Microsoft Outlook 365 availability checks with instant ICS invite generation and conflict prevention.
- Average deployment time for existing CRM + calendar stack is 2 to 5 business days.
